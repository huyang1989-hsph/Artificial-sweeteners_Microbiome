# Artificial sweetener intake, human gut microbiome, plasma metabolome, and cardiometabolic disease risk in free-living individuals

This repository contains the analysis code accompanying the manuscript **“Artificial sweetener intake, human gut microbiome, plasma metabolome, and cardiometabolic disease risk in free-living individuals,”** currently under review at *Nature Metabolism*.

The analyses integrate repeated dietary assessments, gut microbiome profiles, plasma metabolomics, participant characteristics, and prospective cardiometabolic outcomes. They also include an external replication analysis in the MicroCardio Consortium and a sensitivity analysis using centered log-ratio (CLR) transformed microbiome data.

## Sweeteners evaluated

The reported analyses include nine individual artificial sweeteners:

- **Synthetic sweeteners:** acesulfame K, aspartame, saccharin, and sucralose
- **Sugar alcohols:** erythritol, maltitol, mannitol, sorbitol, and xylitol

The corresponding prefixes used in the code are `acesk_`, `aspart_`, `sach_`, `sucral_`, `eryth_`, `maltitol_`, `mani_`, `sorb_`, and `xyli_`. Some preprocessing and modeling sections also retain a `tag_` variable from the source data, but this variable is not included among the nine individual sweeteners displayed in the final downstream figures.

## Code files

| File | Purpose | Main manuscript output |
| --- | --- | --- |
| `LVS_7DDR.sas` | Reads and cleans the 7-day dietary-record data; aligns daily records across two recording weeks; merges nutrient, food, and plant-based diet index variables; and prepares artificial-sweetener intake variables. | Processed dietary-record data used by the downstream analyses |
| `ddr.R` | Assembles participant-level and repeated-measure data, including dietary variables, biomarkers, covariates, fecal-sample timing, and microbiome profiles. It creates the integrated taxonomic analysis object. | Integrated analysis data (`TAXON_ONLY.RData`) |
| `Taxon_AVG.R` | Averages numeric microbiome features, dietary measures, biomarkers, and covariates across repeated measurements for each participant; recodes selected indicator variables; and defines analysis phenotypes. | Participant-level averaged analysis data (`Taxon_use_AVG.RData`) |
| `ELN.R` | Fits elastic-net models at ten mixing-parameter values (`alpha = 0.1, 0.2, ..., 1.0`). Models relate species-level microbiome features to artificial-sweetener intake; downstream reported results focus on the nine individual sweeteners listed above. Species must have prevalence greater than 30%, and tuning uses leave-one-out cross-validation. | Ten `INT_alpha_*_0.3.RData` model-result files used in the core analyses |
| `figures.R` | Combines stable elastic-net features across alpha values; calculates microbiome scores; performs community-level, sparse canonical correlation, metabolite, pathway, and enzyme analyses; and generates the main visualization panels. | Figures 2, 3, and 5; Extended Data Figures 1 and 3 |
| `surv.R` | Conducts Cox proportional-hazards and inverse-probability-weighted survival analyses of metabolite composite scores in relation to incident type 2 diabetes (T2D) and coronary heart disease (CHD). | Figure 6 |
| `replicate.R` | Summarizes and meta-analyzes study-specific odds ratios for T2D in the MicroCardio Consortium; produces overall and sex-specific forest plots and sensitivity/heterogeneity summaries. | Figure 4; Extended Data Figure 2; Extended Data Table 1 |
| `CLR_ELN.R` | Repeats the core microbiome analysis using zero replacement and CLR transformation, reconstructs elastic-net-derived scores, and evaluates their associations with metabolomic features. | Extended Data Figures 4–6; Extended Data Table 2 |

The image filenames created within the scripts are working filenames and do not always match the final manuscript figure numbers.

## Analysis workflow

### Primary analysis

1. Run `LVS_7DDR.sas` to prepare and merge the 7-day dietary-record data.
2. Run `ddr.R` to harmonize dietary, biomarker, covariate, fecal-timing, and microbiome data and create `TAXON_ONLY.RData`.
3. Run `Taxon_AVG.R` to average repeated measurements by participant and create `Taxon_use_AVG.RData`.
4. Run `ELN.R` to fit the elastic-net models across the ten alpha values.
5. Run `figures.R` to conduct downstream multivariable analyses and generate the primary figure panels.
6. Run `surv.R` after the metabolite-score inputs generated by the preceding analyses are available.

### Replication analysis

Run `replicate.R` with the study-specific MicroCardio odds-ratio input files. This branch is independent of the primary individual-level analysis and uses summary estimates as inputs.

### CLR sensitivity analysis

Run `CLR_ELN.R` with the integrated microbiome data, metabolomics objects, and CLR-specific elastic-net result objects available. The script applies compositional zero replacement and CLR transformation before reconstructing the microbiome scores and producing the sensitivity-analysis results.

## Required data and intermediate objects

Individual-level study data are not included in this code collection. The scripts expect locally available source data and intermediate objects, including:

- participant characteristics and biospecimen information (`Basic.csv`);
- biomarker data (`Biomarkers.csv`);
- food-frequency questionnaire data (`FFQD.csv`);
- raw and derived 7-day dietary-record datasets used by `LVS_7DDR.sas`;
- the processed SAS dietary-record file (`mlvs_ddr.sas7bdat`);
- taxonomic abundance and annotation objects (`ReadIn_taxon.RData` and `TAXON_ONLY.RData`);
- participant-level averaged data (`Taxon_use_AVG.RData`);
- plasma metabolomics objects (`MET_pm.RData` and `MET_fea.RData`);
- pooled outcome data for survival analysis (`AS_outcome.csv`); and
- MicroCardio study-specific odds-ratio, sex-stratified, sample-size, and sensitivity-analysis CSV files used by `replicate.R`.

Several project-specific helper files are referenced but are not included here, including `MLVSfunctions.R`, `myfunctions.R`, and `myfunction_2.R`.

## Software requirements

- **SAS** is required for `LVS_7DDR.sas`.
- **R** is required for all `.R` scripts.

Major R packages include `tidyverse`, `data.table`, `caret`, `glmnet`, `vegan`, `CCA`, `CCP`, `PMA`, `ComplexHeatmap`, `zCompositions`, `survival`, `survminer`, `mice`, `meta`, `ggplot2`, `patchwork`, and `cowplot`. Additional packages are loaded within individual scripts; consult the `library()` calls at the beginning of each file for the complete list. The code also references the project-specific `chanmetab` package.

Package and software versions were not recorded in the supplied scripts. For a reproducible computational environment, record `sessionInfo()` after installing the required packages and retain the SAS version and configuration used for the dietary-data preparation.

## Running the code

These scripts preserve the directory structure used for the original analyses and therefore contain hard-coded paths beginning with `~`, as well as calls to `setwd()`. Before running the code:

1. Place the authorized input data and intermediate objects in an appropriate secure location.
2. Update all file paths and working directories for the local environment.
3. Ensure that the project-specific helper scripts and packages are available.
4. Run the scripts in the order described above, unless reproducing only the independent replication branch.

The scripts are provided as an analytic record of the manuscript analyses rather than as a fully self-contained, one-command workflow. Access to the underlying participant-level data is governed by the applicable cohort consent, institutional approvals, and data-use agreements.
